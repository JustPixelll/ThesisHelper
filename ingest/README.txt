Put your source books and papers here as .pdf or .docx files.
Subfolders are supported. Then open ThesisHelper > Library > Index local text.
Use Semantic index after adding an OpenAI API key if you want semantic retrieval.
Semantic indexing sends extracted text to OpenAI and incurs embedding API usage.
Your thesis belongs in workspace/, not here: this folder is evidence only.
Image-only PDFs need OCR; see docs/WINDOWS.md and docs/LIBRARY.md.
Books, keys, drafts, and generated indexes are excluded from Git.
